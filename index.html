          03
          
    Every word is attributable
    
          
    Each render writes a .manifest.json next to the WAV: which recording every word came from, who said it, when, and where in the file. Missing words become 400 ms gaps and are listed as found: false. A render never crashes on a missing word.
    
        
    
        
    {
  "text": "we must act now",
  "output_wav": "renders/out.wav",
  "words": [
    { "token": "we", "found": true,
      "source_file": "myspeech.wav", "speaker": "Firstname Lastname",
      "date": "2003-02-05", "start_s": 12.34, "end_s": 12.56,
      "confidence": 0.97 },
    …
    { "token": "now", "found": false, "gap_s": 0.4 }

          04
          
    Run it on your own corpus
    
          
    Python 3.11, WhisperX for transcription and word alignment, SQLite for the index. A GPU is strongly recommended for transcription.
    
        
    
        
      
          
    1. 
            
      Install
      
            
      python3.11 -m venv .venv && source .venv/bin/activate
pip install torch torchaudio   # CUDA build recommended
pip install -e .
      
          
      2. 
          
    2. 
            
      Ingest a recording
      
            
      mouthpiece ingest corpus/myspeech.wav --metadata corpus/myspeech.json
      
            
      Normalizes to 16 kHz mono, transcribes, aligns word timestamps, writes the index. Metadata (speaker, date, event, source URL, license) is optional.
      
          
      3. 
          
    3. 
            
      Check coverage, then render
      
            
      mouthpiece coverage "we must act now"
mouthpiece "we must act now" -o renders/out.wav
      
            
      Writes a 16 kHz WAV that drops straight into Reaper, plus its manifest.
